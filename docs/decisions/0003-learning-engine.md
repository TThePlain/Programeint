# ADR 0003 — FSRS para retenção; BKT-like para domínio prático

## Estado

**Estado:** implementação inicial na fase 5 (módulos Java + FSRS nas verificações).

## Contexto

Retenção ≠ domínio. Assistir conteúdo não é mastery.

## Decisão

- **Retenção (conhecimento declarativo):** FSRS (ts-fsrs), estado D/S/R por item
- **Habilidade prática:** evidência de exercícios/execuções/testes, não de views
- **Aplicação:** projetos
- **Autonomia:** nível de ajuda do tutor (0–6) pesa na avaliação

Sequência de módulos não é rígida; pré-requisitos geram aviso, o aluno decide.
